When to reach for a library

  • GSAP + ScrollTrigger — real pinning, scrub, snap. The moment pattern 06 goes on a live page.
  • Lenis — smoothed scroll. Half of what makes those sites feel different is just this.
  • Motion — layout and presence animation once you're in React.
  • R3F + drei — only once 2D canvas genuinely runs out.

What keeps it fast

  • Animate transform and opacity only. Everything else repaints.
  • One rAF loop per effect, and IntersectionObserver to pause it offscreen — see js/util.js.
  • Lerp toward targets (v += (t − v) × 0.1) instead of CSS transitions on pointermove.
  • Honour prefers-reduced-motion, and make sure the page reads with JS off.

Where the taste comes from

  • Pick one signature moment. Keep everything around it still.
  • Type does more than motion: one characterful display face, set tight.
  • Fast in (200–350ms), slow out. Never linear.
  • If an effect doesn't make the content clearer or the brand louder, cut it.
